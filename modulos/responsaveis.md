# Responsáveis financeiros

**Menu:** Associados → Responsáveis

A pessoa que recebe e paga a cobrança — geralmente o pai, a mãe ou o responsável legal do
jovem, ou o próprio adulto voluntário.

![Lista de responsáveis financeiros](/assets/img/responsaveis-lista.png)

## O que você faz aqui

Criar, editar, excluir (individualmente ou em lote) e ordenar.

## Campos do cadastro

![Formulário de novo responsável, com "Criar família" marcado](/assets/img/responsavel-formulario.png)

| Campo | Obrigatório | O que faz |
|---|---|---|
| Nome | Sim | |
| CPF | Sim | |
| E-mail | Não | Endereço para onde as cobranças são enviadas |
| Telefone | Não | WhatsApp é o formato preferencial |
| Usuário do WordPress | Não | Vínculo opcional, para quem tem conta no site |
| Foto | Não | |
| Criar família | Não (só na criação) | Marcado por padrão — cria a família já vinculada, poupando uma etapa |

{: .tip }
Deixe **"Criar família"** marcado ao cadastrar um responsável novo, salvo se ele for entrar
numa família que já existe (por exemplo, o segundo responsável de uma família já
cadastrada). Assim você não precisa criar a família à parte logo em seguida.
