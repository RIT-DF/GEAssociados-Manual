# Simulador

{: .note }
> Em construção. Esta página será preenchida quando a funcionalidade for concluída no plugin.

O simulador permitirá testar o efeito de uma regra antes de aplicá-la de verdade — útil para
conferir se um novo desconto ou multa vai se comportar como esperado sem precisar gerar um ciclo
real. Enquanto isso, use o preview embutido no formulário de cada regra
(ver [Motor de regras](rules-engine)) para conferir o cálculo com um plano e alguns membros
reais.
