# Próximos passos

O plugin está em evolução constante. Algumas áreas adjacentes:

## Diagnóstico

A página **GE Associados → Diagnóstico** mostra a saúde do ambiente (versões de PHP, WordPress e
WooCommerce, status do schema do banco). É útil quando algo não funciona como esperado — peça
para o suporte técnico abrir essa página e copiar as informações antes de relatar problemas.

## API REST

Uma API REST está planejada para permitir integração com outros sistemas (sites próprios,
planilhas, BI). Acompanhe atualizações no repositório oficial.

## Relatórios

Relatórios em XLSX e CSV (cobranças, membros, inadimplência) estão no roadmap. Hoje a exportação
de cobranças já está disponível no [Painel de cobranças](charges).

## Módulo Eventos

Um módulo separado para gestão de eventos (acampamentos, atividades, inscrições) está em
discussão. Junte-se à comunidade para opinar.
