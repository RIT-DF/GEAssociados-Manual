# Trilha dos pais e responsáveis

Esta parte do manual é para você, pai, mãe ou responsável de um jovem no grupo escoteiro.
Você não precisa saber nada sobre o plugin nem sobre WordPress — só precisa saber usar as
duas páginas abaixo, que chegam até você por um link.

- [Acompanhar e pagar as cobranças](/responsavel/portal/) — o portal para ver o que você
  deve e o que já pagou.
- [Simular quanto vou pagar](/responsavel/simulador/) — para quem ainda não é do grupo e
  quer saber o valor antes de se inscrever.
