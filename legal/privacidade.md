# Política de Privacidade

Esta página explica o que o GE Associados coleta, onde guarda e por quanto tempo mantém
os dados pessoais tratados pelo plugin.

## Quem é o controlador dos dados

{: .important }
O GE Associados é uma ferramenta disponibilizada pela **RIT — Rede de Inovação e
Tecnologia**. **A RIT não é a controladora dos dados** cadastrados no plugin.
O **controlador dos dados é o próprio grupo escoteiro** que instala e opera o plugin no
seu site — é ele quem decide o que cadastrar, quem tem acesso e por quanto tempo manter.

A RIT fornece o software; o grupo escoteiro, ao usá-lo, é responsável por como os dados
dos seus associados são tratados dentro dele, inclusive pelo cumprimento da Lei Geral de
Proteção de Dados (LGPD) na sua operação.

## O que o plugin coleta

- **De membros (jovens e adultos voluntários):** nome, CPF (ou marcação de "sem CPF —
  estrangeiro"), data de nascimento, data de ingresso, data de fim de cobrança, e-mail,
  número de registro, ramo, seção e foto.
- **De responsáveis financeiros:** nome, CPF, e-mail, telefone e foto; opcionalmente, o
  vínculo com um usuário do WordPress.
- **Da organização:** nome, sigla, CNPJ, contato e endereço.
- **De uso do sistema:** histórico de cobranças, pagamentos, comprovantes anexados,
  histórico de envio de e-mails, e o histórico de acesso ao portal do responsável (data,
  hora e origem de cada acesso).

## Onde os dados ficam

Todos os dados cadastrados no plugin ficam armazenados no **banco de dados do próprio
site WordPress do grupo escoteiro** — a mesma infraestrutura de hospedagem que o grupo já
usa para o site. A RIT não mantém cópia desses dados em servidor próprio; o plugin roda
inteiramente dentro da instalação do grupo.

## Por quanto tempo os dados ficam guardados

Os dados permanecem enquanto o registro correspondente existir no sistema. Desativar um
membro ou excluir uma família não apaga o histórico de cobranças já geradas — o histórico
financeiro é preservado para fins de controle contábil do grupo. Cabe ao grupo escoteiro,
como controlador dos dados, definir e aplicar sua própria política de retenção, de acordo
com a legislação aplicável.

## Quem tem acesso

O acesso ao cadastro é controlado pelo próprio grupo, na tela
[Permissões](/modulos/permissoes/), que define o que cada papel de usuário do WordPress
pode ver e fazer dentro do plugin. O responsável financeiro tem acesso, pelo
[Portal do responsável](/responsavel/portal/), apenas aos dados da própria família.

{: .note }
Esta página descreve o que o plugin faz com os dados, para ajudar o grupo escoteiro a
compor a própria política de privacidade voltada aos associados. Ela não substitui uma
análise jurídica sobre o cumprimento da LGPD pela operação específica de cada grupo.
