# Como usar o Manual

Este manual está organizado em 10 grupos no menu lateral, na mesma ordem em que as áreas
aparecem dentro do próprio plugin. Cada grupo reúne páginas relacionadas — clique no grupo para
expandir e ver as páginas dentro dele.

A URL de cada página pode ser compartilhada — copie o link da barra de endereços e mande para um
colega. Use <kbd>Ctrl+F</kbd> (ou <kbd>Cmd+F</kbd> no Mac) para buscar dentro de uma página, ou
a busca no topo do manual para procurar em todas as páginas de uma vez.
